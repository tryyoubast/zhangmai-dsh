# @deepseek-ai/dsh-api-novel-authoring-http

[English](README.md) | 中文

面向多用户小说创作服务的框架无关 HTTP 适配器。宿主负责解析认证后的 `AuthPrincipal` 并注入数据库领域服务；本包不信任客户端提交的用户 ID、角色或工作区成员关系。

适配器提供工作区和小说创建、工作区成员邀请/列表/角色变更/撤销、所有权转移、归档/恢复、生成任务创建、仅限 Worker 的草稿生成和提案物化、审核/发布、回滚以及持久化上下文读取接口，返回适合非技术 Web 界面的业务状态。成员和工作区生命周期操作都委托给已认证的领域服务；客户端传入的工作区 ID 会与服务端解析的身份进行比对。浏览器身份可以排队生成任务并审核提案，但不会暴露仅限 Worker 的生成和提案路由。Cookie/JWT 解析仍由认证边界负责。

## 当前限制

- 本包是 HTTP 适配器，不是 HTTP 服务器或完整 Web 界面。宿主仍需提供路由、认证/Session 解析、邮件/Redis 控制以及面向浏览器的展示层；可选的生成路由还需要注入 `NovelGenerationWorkflowService` 及其 Provider/存储适配器。
